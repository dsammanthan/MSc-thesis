# MSc-thesis

This repository contains the following files and code used for the master's thesis of Dean Sammanthan:

1. Various traffic assignment codes which process the different scenarios and save their results. These codes are stored as Jupyter notebooks that start with the names "Traffic Assignment".
2. Demand for flow between OD pairs used for the traffic assignments titled "OD.csv".
3. Ownership information used for the ownership outages scenarios in the traffic assignment titled "OwnershipInformationCables.xlsx".
4. Plotting codes in python format such as "delay factor plot.py" and "inverse relationship plot.py".
5. CSV files used in the traffic assignments on the full global network in 2024 titled "2024FullNetworkEdges.csv" and "2024FullNetworkNodes.csv".
6. A notebook which compiles all the results into a single excel file titled "combined_TA_results_all_scenarios.xlsx".
7. The full compiled results of all traffic assignments titled "combined_TA_results_all_scenarios.xlsx".

Please refer to ```system requirements.txt``` for the required packages to run the Jupyter notebooks and Python scripts. For all system directories in the various codes, please adjust accordingly to your local system.
